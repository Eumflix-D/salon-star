홈 화면에 추가해 주세요

홈 화면 앱으로 열면 연주 기록이 더 안전하게 저장되고,
화면도 넓게 쓸 수 있어요.

  1. 사파리로 이 페이지를 열어요
  2. 아래쪽 공유 버튼(네모에 위 화살표 ⬆)을 눌러요
  3. 목록을 내려 '홈 화면에 추가'를 눌러요
  4. 오른쪽 위 '추가' → 홈 화면의 Salon Star로 시작!
  1. 크롬으로 이 페이지를 열어요
  2. 오른쪽 위 점 세 개(⋮) 메뉴를 눌러요
  3. '홈 화면에 추가' 또는 '앱 설치'를 눌러요
  4. '설치/추가' → 홈 화면의 Salon Star로 시작!

⚠ 아이폰은 사파리에서 한 기록과 홈 화면 앱의 기록이 따로 저장돼요. 처음부터 홈 화면 앱으로 시작하는 걸 추천해요.
